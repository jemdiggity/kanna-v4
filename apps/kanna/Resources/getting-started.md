# Kanna

This is your planning agent. It sees this project's Shelf and backlog (right) and makes tasks with you.

1. **Tell it what you want to work on.** "Split the login work into three tasks", "what's waiting?", "start the first one".
2. **It adds tasks to the backlog**, each with a first message for the agent that will do it.
3. **Move to Shelf starts one:** its own agent, branch and worktree. Up to three run at once.
4. **Click a task to work with it.** Park (⌘.) brings you back here.
