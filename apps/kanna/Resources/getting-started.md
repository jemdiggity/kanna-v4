# Getting started

This Desk holds your first task: a terminal on the left, its docs here as tabs.

1. **Start an agent** in the terminal, in your repo: `cd ~/your/repo`, then `claude` or `codex`.
2. **Tell it what you want to work on.** It names this task with `kanna task name "NAME"`, and the name shows in the title bar.
3. **Plan with it.** It can add tasks to the repo's backlog: `kanna task new "NAME" "FIRST MESSAGE"`.
4. **Park** (⌘.) to see the Shelf and the backlog; ⌘. again brings the task back. Move up to three tasks to the Shelf; each gets its own agent, branch and worktree.

Docs, pages and terminals the agent opens (`kanna open md|web FILE`) come up here as tabs.
