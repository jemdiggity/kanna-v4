# Kanna

This terminal is for planning. The Shelf on the right shows this folder's tasks: running, and waiting in the backlog.

1. **Start your agent here:** `claude` or `codex`. `cd` first if this isn't the folder you want; the Shelf follows.
2. **Tell it what you want to work on.** "Split the login work into three tasks", "what's waiting?", "start the first one".
3. **It adds tasks to the backlog**, each with a first message for the agent that will do it.
4. **Move to Shelf starts one:** its own agent, branch and worktree, on the Shelf, which holds three. `kanna task start` runs one in the backlog instead, as many as you like.
5. **Click a task to work with it.** Park (⌘.) brings you back here.
